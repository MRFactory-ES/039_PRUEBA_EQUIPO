Testing Pull requests

Cómo cambiar tu página del tablón con Claude Code

Cada uno tiene su propia página en el tablón del equipo. Vamos a practicar cómo se trabaja entre varios sin pisarnos.

No tienes que saber nada de GitHub. Tú le dices a Claude Code lo que quieres con las frases de estas hojas, y él hace todo lo demás. El proyecto ya le explica a Claude las reglas, así que no se las tienes que contar tú.

El camino de un cambio

Las tres reglas

Solo tu páginaSi Claude te dice que no puede tocar otra cosa, es normal: es la regla.
Siempre en tu ramaNadie trabaja en main, la versión buena. Claude lo sabe.
Siempre pidiendo permisoTodo entra por un Pull Request que aprueba Coke.

Palabras que vas a oír

  • Rama: tu copia de trabajo. Lo que hagas ahí no toca lo de nadie.
  • Pull Request: «he cambiado esto, ¿lo metes?». Es la petición de permiso.
  • main: la versión buena, la que sale en la web. Solo entra lo aprobado.

Antes de empezar · solo la primera vez

Sirve igual en Mac y en PC.

A
Hazte una cuenta en GitHub En github.com, si no la tienes. Pásale a Coke tu nombre de usuario.
B
Acepta la invitación a MRFactory-ES Te llegará por correo. Sin esto no podrás bajar el proyecto.
C
Prepara tu ordenador. Abre Claude Code en cualquier carpeta y escribe:
Comprueba si tengo instalados git y GitHub CLI. Si falta algo, instálalo y ayúdame a iniciar sesión en GitHub con mi cuenta.
Se abrirá el navegador: pega el código que te dé y acepta. Si Claude te pide que escribas tú un comando en la terminal, hazlo.
D
Baja el proyecto a tu ordenador.
Clona el repositorio github.com/MRFactory-ES/039_PRUEBA_EQUIPO en mi carpeta Documentos.
Aparece la carpeta 039_PRUEBA_EQUIPO dentro de Documentos.
E
Abre Claude Code dentro de esa carpeta. En la app, al crear la sesión, elige la carpeta Documentos / 039_PRUEBA_EQUIPO. En la terminal, entra en esa carpeta y escribe claude.
A partir de ahora, siempre abre Claude Code en esa carpeta. Así lee las reglas del proyecto.

¿Ha ido bien?

Comprueba que está todo listo: git, mi sesión de GitHub y el proyecto.

Si Claude dice que sí, ya puedes pasar a la página siguiente.

Claude te pedirá permiso

Antes de ejecutar cosas como git o gh, Claude te pregunta si le dejas. Para este proyecto, acepta: es justo lo que le has pedido.

Cada vez que quieras cambiar algo

En los ejemplos sale Vero: pon tu nombre. Y en la frase 2, lo que tú quieras cambiar.

1
Bajar lo último y crear tu rama
Soy Vero. Bájate lo último de main y crea una rama nueva llamada vero-titulo.
Claude te dice que ya estás en tu rama vero-titulo. El nombre de la rama: tu nombre y qué vas a cambiar, sin espacios ni tildes.
2
Cambiar tu página
En mi página cambia el título por "Hola desde Claude" y pon mi color en naranja.
Claude te dice qué ha cambiado. Puedes pedir lo que quieras de tu página: textos, la lista, el color, añadir cosas…
3
Verlo en tu ordenador
Ábreme el tablón en el navegador.
Se abre el tablón. Pulsa tu tarjeta y verás tu página con el cambio. ¿No te gusta? Vuelve a la frase 2 y pide otra cosa. Esto solo lo ves tú.
4
Subirlo y pedir permiso
Sube mi cambio y crea un Pull Request para Coke.
Claude te da un enlace a tu Pull Request. Ya está: a Coke le llega el aviso. La web del equipo no cambia hasta que Coke lo apruebe.

Puedes hablarle normal

Las frases son para no dudar, pero Claude entiende lo mismo dicho con tus palabras. Si no sabes cómo pedir algo, pregúntale: «¿cómo hago para…?»

Después de subirlo

5
Si Coke te pide un cambio Te llega un aviso de GitHub con su comentario.
Lee lo que dice Coke en mi Pull Request y arréglalo.
Claude lo arregla en tu misma rama y lo sube. El Pull Request se actualiza solo: no hay que crear otro.
6
Cuando Coke lo aprueba En 1 o 2 minutos tu cambio sale en la web del tablón. Luego:
Coke ya lo ha aprobado. Vuelve a main y bájate lo último.
Listo para el siguiente cambio: vuelves a la frase 1 con una rama nueva.

Si algo sale raro

Explícame qué ha pasado, sin tocar nada.
  • Claude habla de un «conflicto»: otra persona ha cambiado lo mismo que tú. Avisa a Coke y lo resolvéis juntos.
  • Claude no encuentra tu página o no sabe quién eres: ¿has abierto Claude Code dentro de la carpeta 039_PRUEBA_EQUIPO? (paso E).
